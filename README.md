# Vinil — любая музыка как с пластинки

Прототип: веб-приложение (PWA, работает на телефоне и устанавливается на главный экран) и расширение Chrome (боковая панель) — **на одном и том же коде**.

## Что уже работает

- **Пластинка слева, видна наполовину**, тонарм справа. Когда трек играет, пластинка крутится на 33⅓ об/мин; в начале трека разгоняется, на паузе и в конце замедляется и останавливается.
- **Тонарм двигается**: опускается на край пластинки, за время трека медленно идёт к центру, в конце поднимается и возвращается на стойку.
- **Звук пластинки (всё синтезируется в браузере, без звуковых файлов):**
  - в начале: игла опускается (удар и шорох), 2 оборота вводной дорожки с треском, потом начинается песня;
  - во время песни: тёплый тембр (срез низа и верха, мягкое насыщение), детонация (лёгкое «плавание» звука раз за оборот), тихий треск;
  - в конце: треск выводной дорожки, щелчки раз за оборот, игла поднимается.
  - Эффект можно выключить, громкость треска регулируется.
- **Поиск в открытых источниках:** Audius (независимые артисты, без ключа) и Internet Archive (общественное достояние, старые пластинки). Можно загрузить **свой mp3** — он тоже зазвучит как винил.
- **Очередь и плейлисты** (создать, добавить трек сердечком, включить весь плейлист).
- **Монетизация (демо):** бесплатно 10 треков в сутки и чёрная пластинка; в Plus — безлимит и 10 цветных пластинок (медь, рубин, кобальт, лес, сорбет, брызги, санглоу, контесса, олива, корица — из ваших референсов и палитр). Оплата пока не подключена: кнопка просто включает демо-режим.
- Светлая и тёмная тема, управление с экрана блокировки телефона (Media Session), офлайн-запуск оболочки.

## Как запустить

**Сайт (и на телефоне):**
```bash
cd app && python3 -m http.server 8000
# открыть http://localhost:8000
```
Для телефона нужен HTTPS: самое простое — включить GitHub Pages для папки `app` или выложить её на Netlify/Vercel/Cloudflare Pages (бесплатно, сборка не нужна).

**Расширение Chrome:**
```bash
./scripts/build-extension.sh
```
Chrome → `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка `dist/extension`. Кнопка расширения открывает Vinil в боковой панели — музыка играет, пока вы листаете сайты. Правый клик по кнопке → «Открыть во вкладке».

## Структура

```
app/                  веб-приложение (без сборки, чистый JS)
  js/audio-engine.js  звук пластинки: цепочка эффектов, треск, игла
  js/vinyl.js         рисование пластинок (11 скинов) и проигрыватель
  js/sources.js       поиск: Audius, Internet Archive, свои файлы
  js/store.js         плейлисты, лимит треков, Plus
  js/main.js          интерфейс
extension/            манифест и фоновый скрипт Chrome-расширения
scripts/              сборка расширения
```

## Что нужно, чтобы запустить это как продукт

### 1. Главный вопрос — откуда брать музыку (важно!)

«Любимая музыка» обычно — это треки крупных лейблов. Их **нельзя легально брать из открытых источников** и проигрывать со своими эффектами:

| Источник | Что есть | Можно накладывать эффект? |
|---|---|---|
| Audius, Jamendo, Free Music Archive, Internet Archive | независимые артисты, CC-лицензии, общественное достояние | да (нужно соблюдать условия лицензий, у Jamendo для коммерции — платная лицензия) |
| Spotify / Apple Music / Яндекс Музыка SDK | весь мейнстрим | **нет**: звук защищён (DRM), доступа к нему для обработки нет, правила запрещают его менять |
| YouTube | почти всё | **нет**: вытаскивать звук из YouTube запрещено правилами |
| Файлы пользователя | что угодно | да — пользователь сам отвечает за свои файлы |

Реальные варианты:
- **A. Открытые каталоги + свои файлы** (как сейчас в прототипе) — законно и быстро, но «любимых» хитов не будет.
- **B. Лицензия на каталог** через дистрибьютора / сервис вроде 7digital, Feed.fm, MediaNet — даёт мейнстрим с правом обработки, но стоит денег (обычно минималка + отчисления за прослушивание), договоры по каждому региону.
- **C. Расширение как «эффект поверх того, что играет во вкладке»**: пользователь включает музыку в своём сервисе, а расширение добавляет треск и тёплый звук. Технически возможно (`chrome.tabCapture`), но правила стримингов это, скорее всего, запрещают — нужна консультация юриста. На телефоне такой вариант не работает.

👉 Рекомендация для старта: **A** (запуск, проверка, нравится ли людям), параллельно узнать условия у лицензиаров для **B**.

### 2. Бэкенд (сервер)
Сейчас лимит 10 треков и Plus хранятся в браузере — их легко обойти. Нужно:
- аккаунты (вход через Google / Apple / Telegram / почта);
- сервер, который считает прослушивания и выдаёт право на трек;
- хранение плейлистов в облаке (чтобы совпадали на телефоне и в расширении).
Варианты: Supabase или Firebase (быстро, недорого) либо свой сервер на Node.js + PostgreSQL.

### 3. Оплата
- Сайт: ЮKassa / CloudPayments (Россия), Stripe / Paddle (остальной мир). Подписка, например, 199 ₽/мес.
- Расширение: оплата через тот же сайт (Chrome Web Store свою оплату больше не даёт).
- Если позже нужно приложение в App Store / Google Play — там своя оплата и комиссия 15–30%.

### 4. Публикация
- Домен + хостинг (статика бесплатно, сервер ~$5–25/мес на старте).
- Chrome Web Store: аккаунт разработчика ($5 один раз), политика конфиденциальности, скриншоты, проверка 1–7 дней.
- PWA на телефоне ставится с сайта; при желании позже — обёртка в нативное приложение (Capacitor).

### 5. Юридическое
Политика конфиденциальности, пользовательское соглашение, условия подписки и возврата, указание авторов и лицензий треков (для CC-музыки обязательно).

### 6. Что доделать в продукте
- Карточка трека с указанием лицензии и ссылкой на автора.
- Пресеты звука: «78 об/мин 1930-х», «Пластинка из 70-х», «Новая пластинка» (почти без треска).
- Свои этикетки и обложки (ещё одна платная функция).
- Сохранение очереди между сессиями, «Похожие треки», радио по жанрам.
- Аналитика: сколько людей доходят до лимита и покупают Plus.

## Ограничения прототипа
- Поиск проверен по документации API, а не вживую (в среде разработки не было доступа к Audius и Archive.org). Обработка звука, пластинка, тонарм, плейлисты и лимит проверены в браузере на своём аудиофайле.
- Если источник не отдаёт CORS-заголовки, браузер не даёт обработать звук: тогда песня играет без тёплого тембра, но треск и игла остаются (приложение покажет подсказку).
